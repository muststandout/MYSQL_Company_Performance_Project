# MYSQL_Company_Performance_Project

# Global Layoffs Analysis | MySQL

## Project Overview
This project uses MySQL to clean, standardize, and analyze global company layoff data. The goal is to transform raw data into a reliable dataset and uncover trends in workforce reductions across companies, industries, countries, and time periods.

## Key Business Questions
- Which companies reported the highest total layoffs?
- Which countries and company funding stages experienced the most layoffs?
- How have layoffs changed over time, both annually and monthly?
- What are the cumulative layoff trends over time?
- Which companies ranked among the top five for layoffs each year?

## Skills Demonstrated
- **Data Cleaning:** Removing duplicates, standardizing inconsistent values, and handling missing data.
- **Data Transformation:** Converting date fields and preparing data for analysis.
- **Exploratory Data Analysis:** Aggregating and comparing layoffs across companies, countries, and time periods.
- **Advanced SQL:** Using CTEs, self-joins, window functions, rolling totals, and `DENSE_RANK()`.

## Project Outcome
Developed a structured dataset and SQL queries to examine layoff patterns, identify companies with the largest workforce reductions, and track trends over time.
